# Web de Claridez

Esqueleto técnico mínimo del frontend de Claridez. Su pantalla confirma que React, TypeScript estricto, Vite y las pruebas funcionan juntos; no constituye una propuesta visual ni una navegación del producto.

## Requisitos

- Node.js 24.18.1.
- npm 11.16.0.
- Dependencias fijadas por `package.json` y el `package-lock.json` raíz.

## Instalación reproducible

Desde la raíz del repositorio:

```text
npm ci
```

Los comandos oficiales del monorepo se ejecutan también desde la raíz y están documentados en el `README.md` principal.
