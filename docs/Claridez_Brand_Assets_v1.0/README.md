# Claridez — Activos de marca v1.0

Paquete oficial basado en la ruta elegida **Centro Convergente / Centro Modular**.

## Concepto del isotipo

Una **C implícita** construida sobre una retícula 3 × 3 mediante siete módulos redondeados. La apertura derecha representa claridad y avance; la estructura modular representa la integración comercial, operativa y financiera. El módulo teal funciona como punto de acción y crecimiento.

## Colores

- Claridez Navy: `#0F172A`
- Slate Blue: `#1E293B`
- Claridez Teal: `#14B8A6`
- Soft Teal: `#CCFBF1`
- Fondo: `#F8FAFC`

## Tipografía

El wordmark entregado está convertido a trazados vectoriales para conservar su apariencia sin requerir fuentes instaladas. Su construcción utiliza **Inter Display SemiBold** como base geométrica. La interfaz del producto utiliza **Inter**; la comunicación de marca puede mantener **Plus Jakarta Sans** conforme al documento de dirección visual.

## Carpetas

- `svg/`: archivos vectoriales escalables.
- `png/`: logos e isotipos transparentes en varios tamaños.
- `web-icons/`: favicon, iconos PWA y versión maskable.
- `CLARIDEZ_PREVIEW.png`: vista general del sistema.

## Uso recomendado

- Logo horizontal color: fondos blancos o muy claros.
- Logo horizontal blanco: fondos navy, slate u oscuros.
- Isotipo color: favicon, sidebar contraído y avatar de marca.
- App icon navy: aplicación principal y perfiles digitales.
- Monocromático: contratos, sellos, documentación y usos de una tinta.

## Restricciones

- No deformar ni rotar el símbolo.
- No alterar la posición del módulo teal.
- No cambiar la retícula o separación entre módulos.
- No utilizar sombras, contornos ni efectos tridimensionales.
- Conservar contraste suficiente alrededor del logotipo.
