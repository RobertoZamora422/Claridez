## Jerarquía documental

- `CLARIDEZ_FUNDAMENTOS_DE_MARCA.md` es la fuente principal para propósito, posicionamiento, personalidad, tono y lenguaje de marca.
- `CLARIDEZ_DIRECCION_VISUAL_OFICIAL.md` prevalece exclusivamente en decisiones visuales, como concepto creativo visual, paleta, tipografía, layout, componentes y tokens.
- La prevalencia visual no reemplaza ni invalida los fundamentos estratégicos de marca.

## Control de cambios

Estas copias no deben editarse para introducir correcciones locales, reinterpretaciones o decisiones nuevas. Para actualizar una copia controlada se requiere:

1. Una nueva fuente oficial autorizada.
2. Sustitución consciente del documento completo.
3. Registro de su versión conocida y fecha de incorporación.
4. Recálculo y actualización del hash SHA-256.
5. Revisión de la jerarquía y de los documentos que dependan de ella.

Las propuestas o notas de trabajo deben almacenarse fuera de las copias controladas y no presentarse como identidad oficial.
